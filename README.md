# 🌸 Gull Boutique

A full-stack e-commerce web application built for a women's clothing boutique, featuring a customer facing storefront, an AI-powered chatbot, and a secure admin panel with full CRUD functionality.

**Live Demo:** [gullboutique.infinityfreeapp.com](https://gullboutique.infinityfreeapp.com/gull_boutique/)
*(Note: the AI chatbot only works on the local/localhost version — see "Known Limitations" below.)*

---

## Features

### Customer-Facing
- Responsive Home page with auto-scrolling hero banner
- "Shop by Category" section with a smooth auto-scrolling carousel
- Product listing with category filters and live search
- Individual product pages with star ratings, customer reviews, and related products
- Wishlist (session-based)
- Contact form (saved to database)
- AI-powered chatbot for customer questions (Google Gemini API)
- Floating WhatsApp button
- Newsletter signup
- Policy pages: Shipping, Returns & Exchanges, Terms of Service, Cloth Care
- Fully responsive (mobile, tablet, desktop)

### Admin Panel
- Secure login system (hashed passwords)
- Dashboard with key stats
- Full CRUD for Products, Categories, and Contact Messages
- Image upload for products and categories

---

## 🛠️ Tech Stack

- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** PHP
- **Database:** MySQL
- **AI Integration:** Google Gemini API (Interactions API)
- **Version Control:** Git & GitHub
- **Deployment:** InfinityFree (free PHP/MySQL hosting)
